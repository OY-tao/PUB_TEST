## 4. 判定口径与独立核验

控制器 `judge()` 对每个 variant 检查全部 64 个 rank（node = rank // 16），每个 rank 需同时满足 6 项：

| 文件 | 字段 | 要求 |
|---|---|---|
| `result.json` | `precision_passed` / `precision_only` | 均为 `true` |
| `result.json` | `operators` | `{}`（未采集性能算子的断言） |
| `result.json` | `buffer_reused` | `true` |
| `precision.json` | `passed` | `true` |
| `exit.json` | `code` | `0` |
