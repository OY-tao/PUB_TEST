## 3. 脚本 9 处改法（指南 §十·五，已全部落地）

1. `NODES` 8 台且 `node 号 = IP 末位 − 4`；新增 `PERF_NODES` / `PREC_NODES` 两个集合常量；
2. `EP_NODES`（性能）`64→[0,1,2,4]`、`32→[5,6]`、`16→[7]`、`8→[7]`、`128→[0..7]`；
   精度另用 `PREC_EP_NODES`（`8→[3]`，即 `.7`），两集合用 `set_phase()` 切换；
3. `container_of` **禁用子串猜测**：`--containers` 必须显式绑定 8 台（默认 8 台同名新容器），缺一台 `sys.exit`；
4. `STAGE` / `STATE_PATH` / 所有 CSV 名 `round2*` → `round3*`；
5. `stage_gate` 改判 PR head：`is_pr_head` / `not_origin_main` / `base_ancestor` /
   `same_container_image` / `container_bound` / `same_interpreter` / `deep_ep_module_path` /
   `deep_ep_buffer_sha`(==`f825a679…`) / `qp_plans_unset` / `cards_idle_all8`（8 台各 16 卡空闲）；
6. `stage_precision` / `precision_argv` 加 EP128；EP128 支持 `--epr-tiers main|probe|main,probe`
   （主档 epr=4 / 探针 32，按档位重裁 B 组 topk 上限），CSV 增加 `epr_tier` 列分开报；
7. `perf_argv` 断言目标 host 集合 ∩ `{30.104.128.7}` = ∅（混入 `.7` 直接作废）；
8. `env_prefix` 把 `ENV_SITE` 放 PYTHONPATH 首位、命令显式用 `ENV_PYTHON`、`unset QP` 并
   `env -u DEEPEP_CLOS_QP_PLANS` 起跑；删掉 R2 遗留的 `SHMEM_UDMA_CONNECT_TIMEOUT_MS=300000`；
9. `precision_argv`(EP128) 不注入 QP 变量；`perf_waves` 改 R3 波次（性能 7 台两波、
   精度 EP128 独占一波 + EP8-64 一波打满 8 台）。

**额外修正（R2 遗留缺陷）**：`run_prec_ep` 原先只从首节点 `collect_json`，多机时首节点
只有本机 16 个 rank，EP32/64/128 会全部误判 `failed_judge`。现改为**逐节点收集后合并再判定**
（仅读取判据所需的 json，不回传原始产物，符合既定「产物不回传」口径）。
